# Prompt Examples

These prompts are starting points. Treat them as product fixtures, then adapt them to your own UI controls, moderation rules, and customer input.

## Premium Campaign Visual

```text
A premium campaign visual for a modular desk lamp, warm interior scene, accurate product geometry, soft shadows, tasteful negative space for headline text
```

## Detailed Poster

```text
A clean product poster for a smart notebook, readable title area, neat handwriting details, realistic paper texture, editorial lighting, high-end stationery brand style
```

## Multi-Reference Edit

```text
Use the first image as the product reference and the second image as the room style reference. Place the product naturally in the room, preserve product shape and logo placement, realistic scale.
```

## Prompt Hygiene

- Keep customer-private data out of examples, screenshots, and public issues.
- Store the final prompt version with the task ID for debugging.
- For reference media workflows, validate file type, size, and access before submit.
